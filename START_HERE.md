# Start here - follow these steps first

1. Extract this ZIP into `Documents\Projects`.
2. Open the extracted `Document_Review_Workflow_Portfolio_Project` folder in VS Code.
3. Open **Terminal > New Terminal**.
4. Run `py --version`.
5. Run `py main.py sample_documents`.
6. Run `py -m unittest discover -s tests -v`.
7. Open `outputs/review_report.json` and inspect the conflict and missing-field sections.
8. Follow the Friday task in `PORTFOLIO_NOTES.md` and your separate Internship Deadline Portfolio Sprint PDF: add `contract_reference`, update the schema, and write a test.

The current program uses rule-based extraction, not a live AI model. Be accurate about this in your portfolio. Use fictional documents only.
